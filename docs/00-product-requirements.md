# 產品規格｜English Learning Player

## 1. 目的與使用者
以一個 Flutter App 在 macOS、iOS、Android、Web 進行英文精聽，教材通常是 M4A/MP3 + 英文 SRT + 中文 SRT。使用者會在 Mac 整理 iCloud Drive 的「英文學習」資料夾，預期其他裝置以**同一 App 帳號**取得教材與續播位置。Web 納入正式支援範圍，實作與發布驗收由 [WP-17](14-web-platform.md) 追蹤。

## 2. MVP 可驗收需求
| ID | 需求 | 驗收觀察 |
|---|---|---|
| FR-01 | 四平台 Flutter App | Android、iOS、macOS、Web 可啟動。Web 以公告支援的瀏覽器與視窗尺寸驗收。 |
| FR-02 | 手動匯入音訊與 SRT | M4A/MP3 成功入庫；英文、中文可個別附加/替換 |
| FR-03 | 自動識別 SRT | 同檔名主體及語言尾碼自動配對，歧義需人工確認 |
| FR-04 | 播放、暫停、Seek、0.5–2× | 切換教材與速度後狀態正確 |
| FR-05 | 逐句字幕與點擊跳轉 | 目前句高亮；點擊句子 Seek 至其開始 |
| FR-06 | 單句循環 | 依英文字幕 cue 邊界重播，不漂移至下一句 |
| FR-07 | 隱藏翻譯、精聽揭露 | 盲聽 → 顯示英文 → 顯示中文 → 下句 |
| FR-08 | 收藏與上次位置 | 重啟裝置後仍可恢復 |
| FR-09 | 同帳號跨裝置教材同步 | Mac 上傳之教材能在 iPhone、Android、Web 列表可見並按需下載。 |
| FR-10 | 同帳號進度同步 | 在另一裝置或 Web 開啟教材時，從已確認的播放位置續播。 |
| FR-11 | Mac 來源資料夾綁播放清單 | 使用者授權後掃描，新增/修改檔案自動匯入 |
| FR-12 | 可離線播放已下載教材 | 網路中斷仍可播放、收藏，恢復後同步 |
| FR-13 | 字幕時間偏移 | 手動修改 offset，不改原始 SRT，跨裝置一致 |
| FR-14 | 背景音訊 | 依各平台可用能力測試鎖屏/耳機控制 |

## 3. 一條 E2E 驗收旅程
1. Mac App 設定 iCloud Drive / 英文學習 綁定「英文新聞」播放清單。
2. 在來源資料夾加入 `article.m4a`、`article.en.srt`、`article.zh-TW.srt`。
3. 來源掃描發現完整音訊；檔案尚未完整下載時先等待並重試。
4. 匯入並解析字幕，匹配音訊，指派穩定教材 ID，UI 顯示「上傳中」。
5. 雲端上傳成功，Firestore 發佈 metadata，其他裝置可看到教材。
6. iPhone 以同 App 帳號取得 metadata，按需下載媒體與字幕。
7. iPhone 播放，使用者點一段字幕重聽，播放至 12:35，暫停並確認進度已同步。
8. Mac 開同教材，預設 12:35 續播；離線操作須可排隊並依衝突規則合併。

## 4. 產品邊界
- **MVP**：音訊 M4A/MP3、SRT、Flutter 四平台、Firebase 帳號＋媒體同步、Mac iCloud 資料夾、基本精聽與收藏。Web 首版使用瀏覽器選檔、私有儲存與 Google 登入，能力及發布門檻見 WP-17。
- **後續**：MP4 影片播放、iOS 直接監控 iCloud 任意資料夾、Mac 登入常駐 Agent、詞典/AI/錄音跟讀、分享教材、字幕自動生成。
- **非目標**：重做 iCloud Drive、取代 iCloud 的即時同步協定、保證 App 被 OS 終止仍能即時監控；即時遠端控制其他裝置音訊。
- **同步語義**：「雲端可取得」不等於「已下載本機」；預設按需下載，大檔案避免手機背景自動下載。

## 5. 可用性與安全
- 繁體中文 UI 預設；支援動態字體/VoiceOver/TalkBack、鍵盤操作。
- 不在未授權情況下讀取 iCloud 其他位置或把任意檔案上傳雲端。
- 沒網路/雲端故障時不阻斷本機學習，向使用者顯示同步狀態與失敗原因。
- 清除來源檔案不等於刪除學習資料；使用者必須明確選擇「移除雲端教材」。

## 6. 尚待產品確認
登入方式（Email/Google/Apple 等）、預設離線下載策略、上傳容量限制、音訊與字幕是否允許由其他來源加入、刪除保留期限。由 Stage 1 記錄 ADR，Stage 2 可以使用文件中的保守預設但不可私自開通付費服務。
